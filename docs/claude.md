This is a directory for the portal for the Bronx Conservatory of Music, which is a non-profit that helps provide low-cost music lessons in the Bronx.

The parent directory is a general directory of apps that we've built.  There are patterns that are worth noting in case we need to solve similar problems.

web_applications/cub_scouts is a site that has a well-built top menu and UI.  It has:
- general php infrastructure (including activity log, email log, lib mutator classes, php / eval pattern, modal patterns)

hackley-clubz/www is an web application that has a few features:
- general php infrastructure (including activity log, email log, lib mutator classes, php / eval pattern, modal patterns)
- gatekeeper (allows toggling features)
- api (for iOS and Android, in hackley-clubz/ios and hackley-clubz/android)
- admin features in maintenance like viewing server logs, restarting python services, importing flows

tasks.hackleyclubz.org: a very simple web application with php / mysql infrastructure
